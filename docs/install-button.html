“Install with SideStep” button

Drop this on any page. If the visitor already has SideStep installed, the button opens it straight onto the app’s Install page (they tap Install). If not, it falls back to downloading the one-click installer that walks them through setup first.

How it decides installed vs. not

A custom URL scheme gives no direct “is it installed?” signal, so we infer it: after firing sidestep://… we watch for the page losing focus / visibility within ~1.5 s. If SideStep launches, the browser backgrounds and we know it’s installed. If nothing happens, we reveal the installer-download fallback. A URL never installs anything on its own — SideStep only lands on its Install page and the user taps Install.

The snippet

Copy the <span> and the <script> once per page. Set data-repo to owner/repo and data-installer-base to wherever your Install owner--repo.app files are hosted (or drop that attribute to hide the fallback).

<span class="sidestep-install"
      data-repo="johnbuckman/magnatune-app"
      data-installer-base="https://johnbuckman.github.io/SideStep/installers/"></span>

<script src="sidestep-install.js" defer></script>
