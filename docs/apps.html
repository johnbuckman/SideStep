How the buttons work

Three steps, the first time

1

Click on a Mac

If SideStep is installed it opens and asks to install the app. If not, the button downloads that app's installer.

2

Plug in the device

The installer gets SideStep, then walks you through the cable, Trust and Developer Mode, and signing in with an Apple ID (a free one works).

3

Trust it once

On the device, open Settings ▸ General ▸ VPN & Device Management and trust your Apple ID. SideStep keeps the app signed and up to date from then on.

Making an app of your own? SideStep Wizard builds the same one-file installer and button for any GitHub project. To add an app to this catalog, open a pull request on GitHub.
